Data provenance
This software processes publicly available data from the Integrated Postsecondary Education Data System (IPEDS), maintained by the National Center for Education Statistics (NCES), U.S. Department of Education.
The IPEDS data are not owned by the authors of this repository. This project does not claim ownership of the underlying IPEDS data.
The purpose of this repository is to provide reproducible code for downloading, cleaning, harmonizing, and compiling IPEDS data into longitudinal files that are easier to use for analysis.
The resulting data files are maintained separately in the IPEDS_data repository. Users should consult that repository and the documentation accompanying each release for information about data provenance and the applicable terms.
